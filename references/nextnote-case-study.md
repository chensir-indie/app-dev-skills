# NextNote: lessons from the original workflow

The original NextNote workflow combined image-generated art with an editable web template. Its historical matrix was nine locales × two device classes × nine story pages. The pages covered capture, animated covers, animated emoji, writing, rich content, AI assistance, search, organization and platform adaptation. This is an example, not the default product story for other apps.

Repeated comparison exposed practical failures: HTML headline proportions differed from the AI reference; branding was repeated too often; animated covers and emoji lacked phase/pose details; long labels were clipped or covered by foreground cards. The reusable lessons are equal-size visual comparison, shared typography, explicit layer ownership, real motion cues and checking the entire locale matrix.

The public case post described 162 covers and 621 editable text layers. These are historical project-specific results, not a guarantee of this generic toolkit or a new benchmark. The original private implementation and raw audit files are not included in this repository. The starter is new, minimal original code with synthetic UI, not a reproduction of the full NextNote system.
