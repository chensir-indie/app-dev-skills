# Store handoff and public case studies

## Handoff stages

Distinguish generated, automated-pass, visually reviewed, upload-ready, uploaded, remote-verified, submitted, approved and publicly available. Mark exactly the stage supported by evidence. Use the project's authorized upload mechanism; this skill does not ship a store uploader or credentials.

Before an authorized store mutation, freeze candidate identity, locale/device/slide matrix, source provenance, PNG hashes and order. Re-read all affected remote cells after saving; verify provider state and order. Apple may transform assets, so if exact remote hashes are not available, record the supported comparison and its limitation instead of asserting byte identity. Check the full review requirements with the app's release workflow. Approval may expose a build automatically: preserve or explicitly authorize release mode. Never change protected legal/privacy/subscription metadata as a side effect of screenshots.

## Public case study

Explain the original problem, why art and web layout are separate, the design iteration, localization audit, final output and limitations. Cite concrete evidence for counts and results. Remove private paths, customer notes, identifiers, signing details, unpublished metrics and proprietary source. Link to public artifacts only. Include screenshots or a contact sheet with reuse rights; a public post does not automatically grant an open-source license to its image.

For X, use concise platform-native copy and a readable 2–4 image sequence when it helps. For Xiaohongshu, use a clear Chinese title, short practical paragraphs and legible vertical images. Follow the user's language choice; English on X and simplified Chinese on Xiaohongshu are examples, not universal rules.

Posting needs the user's explicit instruction. After publication, record actual account, post ID, canonical link, timestamp and visible result. Publishing receipt, moderation pending and public accessibility are different. If login or a publishing control blocks completion, preserve the draft and state the blocker. Reconcile an uncertain result before retrying to avoid duplicate posts.
