# iPhone Duo Adaptation

This compatibility entry is intentionally in English. The package's instructions and generated rule documentation are maintained in English at the user's request.

Read the [English documentation](README.md) for supported frameworks, inputs, installation, preflight, invocation, workspace rules and delivery. Read the [Agent workflow](SKILL.md) when executing an adaptation.

The goal is to **help adapt and optimize an existing application for iPhone Duo**. The main flow is **whole-app layout analysis → adaptation recommendations → complete HTML prototype**. Preserve the original app's design with the smallest necessary changes under the [migration/pose-review contract](references/migration-review.md). [BUILD WEB APPS](references/build-web-apps.md) is the preferred construction/refinement and rendered-QA workflow. Show applicable named Duo environments with one stateful app and same-state original/adapted comparisons; keep review controls outside product UI and assumptions explicit. Deliver editable local source and actual browser/visual evidence.

Use the [device-presentation contract](references/device-presentation.md) for actual device exterior references, calibrated screen geometry, posture versus rotation, a device-focused opening view and separate shell/app visual checks. Keep diagnostics in a collapsed inspector.

The collection discovery link resolves to the canonical source; this entry creates no additional installation or runtime dependency. The [workspace-rule contract](references/workspace-rules.md) keeps reusable guidance and project conventions separate. [Validation](references/validation.md) distinguishes Skill/runtime checks, final prototype review, and later native-device acceptance.
