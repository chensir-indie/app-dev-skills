# 竞品 App 拆解技能：验证记录

日期：2026-10-20。对象：[app-competitor-analysis](../skills/app-competitor-analysis/SKILL.md)。本轮完成技能编写、现有摄影类材料试跑、独立执行评估及跨品类迁移测试。结论是：在本轮样本中，技能能够输出有依据的视觉分析、任务状态与技术机制，并保留不完整的证据边界；这不代表所有竞品的当前版本都已实测。

## 1. 技能交付内容

| 部分 | 实际工作要求 |
|---|---|
| 范围与身份 | 单 App 深拆、完整清单综合、材料有限三种工作方式；平台、包名/商店身份、版本、日期分开记录 |
| UI 风格 | 查看真实像素；拆信息层级、字体特征、色彩职责、几何、图像、组件、密度与状态；区分宣传包装和 App 界面 |
| 核心交互 | 沿用户任务追踪入口、动作、反馈、结果、继续与恢复；解释关键对象及生命周期；区分界面反馈与持久化完成 |
| 核心技术 | 输入→触发→处理→输出→状态/存储→消费者；区分检索、生成、分割、识别、匹配与导出；追调用而非仅找名称 |
| 商业与约束 | 只分析影响核心任务的权益、付费、权限、离线、内容供给等机制；不虚构收入、留存或热门程度 |
| 跨 App 取舍 | 先保留完整清单，再按不同机制选深样本；每项采用/改造/暂缓建议说明依据、适用条件、代价和最小验证 |
| 交付与检查 | 报告模板、证据模型、可选 JSON 台账、Python 标准库校验器、行为评估规则、原创合成测试 |

详细规则按需读取，入口不强迫每个小问题输出完整长报告。技能目录独立可用，不依赖摄影项目或相邻技能，也不自动实施产品改动或发布。

## 7. 同日修订：以完整功能结构和关系图开篇

用户指出上一版主要是文字，缺少完整产品功能图。这是交付形态和分析范围的实际缺陷：主任务步骤表没有表达模块层级、辅助功能、可选分支或页面关系。此次将四张图写入技能的默认 HTML 合同，并在报告标题之后、结论与长文之前展示。

- **功能全景**：产品 → 模块 → 子功能，覆盖现有材料支持的核心、辅助、结果与访问边界。44 个对象共 **501 个功能节点**。分组是分析结构，不冒充真实菜单；资料不足的页面、能力和实现用明确的未知节点保留。
- **核心任务图**：带方向、条件、可选支路与回路。已恢复的账号/权限、额度、导入、保存/丢弃、继续拍摄和失败恢复分别呈现。拍后编辑、双机、收藏等辅助能力不会被自动串成必经步骤。
- **页面关系图**：有历史路由资料的产品呈现具体页面/区域；缺少路由资料的产品明确标为概念状态图，连线标推断，不将三个任务状态包装成完整导航。
- **技术链路图**：区分参考生成/检索、叠层显示、真实捕获、缓存和持久保存。未知内部机制保持未知；已有调用链不因可视化而升级成运行证明。

每页均可切换四种图、点击节点看说明与来源、放大关系图。功能树在手机上纵向重排，宽关系图只在自身容器内移动，避免把文字缩成不可读尺寸。无脚本时全部图仍可见；打印全部图，并保留正文、引用和证据边界。素材仍使用原有两张实际图片，图解没有伪造新的竞品截图。

验证：先加入缺少图谱、悬空连线、重复位置及无来源事实的失败用例，再实现结构校验。累计 **39 项技能 Python 测试 / 44 项根目录 Python 测试**通过，**3 项 HTML 浏览器测试**覆盖键盘选择节点、图切换、缩放、来源跳转、打印和状态恢复；仓库 `npm run check` 通过。

实际逐页浏览 44 份报告、176 张图，检查节点交互、图切换、内部锚点、SVG 文字边界及 1600px / 390px 宽度；零页面脚本错误、零外部网络请求。检查发现返回连线的标签超出画布底边，已用原创笔记类示例复现失败，扩展回路线保留空间后浏览器回归通过，并重新导出全量报告。最后补全两份报告的辅助功能、纠正一份来源映射后，仅这三份 HTML 发生变化，已分别复测。

主执行者查看了功能密集图、任务分支图、技术链路图、页面导航图、稀疏证据图以及手机和打印截图。样例 PDF 用于检查打印输出，不代表逐页印刷验收。节点和连线的结构检查不能证明功能真的可用；本次是对当前存档的可视化拆解，当前产品全功能穷尽、竞品真机行为和新增像素证据仍未完成。

## 8. 同日修订：核心证据缺失后的主动补证

用户指出大量缺失不能只用标签处理。新增 `references/evidence-acquisition.md`，将补证纳入入口、证据模型、报告模板和行为评估：定位会影响决策的问题 → 定义闭合所需证据 → 排优先级 → 实际采集和检查 → 核对身份/版本 → 更新图与正文 → 复核是否闭合。公开资料可取得时，不能把“下一步查官网”作为已完成研究。

记录 `queued / attempted / partial / resolved / blocked / deferred / out_of_scope`，区分未查、查过但证据不够、部分回答和真实访问障碍。失败后选择有实质差异的来源或渠道；图片渠道失败时，文字提取不关闭视觉缺口。不能因私有算法未知无限追索，也不能因一个 URL 失败就宣布整个产品无数据。报告交付、问题闭合与运行验证分开计数。
