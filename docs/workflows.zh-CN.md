# 工作流边界

[English](workflows.md)

维护参考：修改技能职责或交接时使用。用户直接从[技能表](../README.zh-CN.md#选择技能)调用即可。

| 技能 | 默认终点 | 边界 |
| --- | --- | --- |
| 竞品分析 | 有证据的报告与产品建议 | 推断保持标注；分析不代表设计获批 |
| 分层 HTML | 可编辑页面与浏览器对比 | 概念／评审可提前结束；原型截图不是真实 App 截图 |
| iPhone Duo | 整体分析 → 建议 → 完整 HTML 原型 | 明确仅要建议时提前结束；原生实现／真机验收独立 |
| 商店封面 | 可编辑源码与经过审查的语言／设备／页面导出 | 导出不等于上传授权 |
| 应用发布 | 用户指定的本地或平台阶段 | 精确 TestFlight 成功回执即结束上传；处理、分发、审核和公开发布分别确认 |

具体执行和验收由对应 `SKILL.md` 定义。跨阶段传递已有产物路径／哈希、来源／状态、观察与推断、完成的检查和剩余缺口。保留已有决策与授权，交接不增加审批环节。

Duo 全量规则、实现前填好的交接、项目约定与浏览器证据仍遵循[工作区规则合同](../skills/iphone-duo-adaptation/references/workspace-rules.md)。本合集账本记录维护证据，不代表目标 App 验收。
